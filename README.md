# Mineworld game project

Java 21과 LWJGL 3로 만든 1인칭 복셀 샌드박스입니다. 저해상도 화면을 최근접 방식으로 확대해 도트 아트 느낌을 내며, 지형과 나무가 생성되는 월드에서 블록을 캐고 설치할 수 있습니다. 1.7 시대의 주요 블록·재료·도구·음식 아이템 카탈로그, 36칸 인벤토리와 조합 레시피가 포함되어 있습니다. 문은 열고 닫을 수 있고, 침대는 두 칸으로 설치되어 부활 지점을 설정합니다. 월드는 사용자 홈 폴더에 저장할 수 있습니다.
화면 밖 청크는 시야 절두체로 제외하며, 기본 시야 거리는 64블록입니다.
블록은 위쪽에서 받는 햇빛과 횃불 주변 조도에 따라 밝기가 달라지고, 물은 반투명 표면으로 표시됩니다.
평원·산악·해변·사막 생물군계가 작은 지역 단위로 생성되며, 저지대 바다와 드문 작은 연못도 나타납니다. 시작 지점은 평원입니다. 마우스 휠로 핫바를 순환하고 선택한 블록이나 횃불이 화면 오른손에 표시됩니다. 5분 주기의 새벽·낮·노을과 원형 해·달, 원판 안의 도트 명암으로 표현한 달 위상, 별, 별똥별이 표시되며 완전한 밤 없이 주변 밝기를 유지합니다.

## 실행

Windows에서 Java 21을 설치한 뒤 저장소 루트에서 실행합니다.

```powershell
.\gradlew.bat run
```

## 조작

| 입력 | 동작 |
| --- | --- |
| W/A/S/D 또는 방향키 | 이동 |
| W 빠르게 두 번 누른 뒤 유지 | 기본 이동 속도의 5배로 전방 질주 |
| Space 한 번 | 점프 |
| Space 빠르게 두 번 | 비행 켜기/끄기 |
| 비행 중 Space 길게 누르기 | 상승 |
| 비행 중 Left Shift 길게 누르기 | 하강 |
| Left Shift (비행 중이 아닐 때) | 달리기 |
| 마우스 이동 | 시점 회전 |
| 왼쪽 짧게 클릭 | 바라보는 면에 선택한 블록 설치 |
| 왼쪽 버튼 0.4초 이상 누르기 | 바라보는 블록 캐기 (누르고 있으면 반복) |
| 오른쪽 클릭 | 블록 설치, 문 열기/닫기, 침대 스폰 지점 지정 |
| 1–9 | 핫바 첫 9칸 선택 |
| 마우스 휠 | 핫바 순환 |
| E | 인벤토리 열기/닫기 |
| 인벤토리에서 Tab | 아이템 카탈로그 열기/닫기 |
| 인벤토리 왼쪽 클릭 | 아이템 묶음 들기/놓기, 레시피 제작 |
| 인벤토리 오른쪽 클릭 | 아이템 절반 들기 또는 하나 놓기 |
| 카탈로그에서 카테고리 클릭 | 블록·재료·도구·음식·기타 아이템 보기 |
| 카탈로그에서 아이템 클릭 | 64개 묶음을 커서에 가져오기 |
| 조합대 오른쪽 클릭 | 3×3 조합 화면 열기 |
| 조합 화면 위/아래 방향키 또는 휠 | 레시피 목록 이동 |
| 문 설치 | 바닥에 두 칸 높이로 설치; 오른쪽 클릭으로 열고 닫기 |
| 침대 설치 | 두 칸 길이로 설치하고 그 위치를 스폰 지점으로 지정 |
| 횃불 설치 | 바닥에 놓거나 벽 옆면에 붙여 기울어진 방향으로 설치 |
| 월드 바깥으로 추락 | 저장한 스폰 지점에서 부활 |
| Esc (게임 중) | 게임 메뉴 열기 |
| Esc (일시정지 중) | 게임으로 돌아가기 |
| F3 | 마우스 시점 다시 잠금 |
| 커서가 풀린 상태에서 게임 클릭 | 시점 조작 다시 잠금 (해당 클릭은 블록 조작에 사용되지 않음) |
| 게임 창 포커스 잃기 | 마우스 잠금 해제; 다시 게임을 클릭하면 캡처 |
| 메뉴에서 마우스 클릭 / 방향키 / Enter | 메뉴 선택 및 실행 |
| 월드 목록에서 월드 더블클릭 | 월드 시작 |
| 월드 이름 입력 중 Backspace | 글자 지우기 |
| F5 | 월드 저장 |
| F9 | 저장된 월드 불러오기 |

시작 메뉴의 **Singleplayer**에서 저장 월드를 선택하거나 새 월드를 만들 수 있습니다. 게임 메뉴에서 월드 저장 후 타이틀로 돌아가거나 게임을 종료할 수 있고, 플레이 중에는 1분마다 자동 저장됩니다.

인벤토리의 **ITEM CATALOG** 탭에서 블록, 재료, 도구, 음식, 기타 아이템을 찾아 가방이나 핫바로 옮길 수 있습니다. 인벤토리에서 기본 레시피를 만들고, 월드에 설치한 조합대를 오른쪽 클릭하면 도구·건축 블록을 포함한 추가 레시피를 사용할 수 있습니다. 저장 파일은 새 인벤토리 형식으로 자동 변환되며, 이전 월드의 지형·문·침대 상태도 읽습니다.

기본 저장 위치는 `%USERPROFILE%\.mineworld-game-project\`입니다. 기존 기본 월드는 `world.dat`에 유지하고, 새 월드는 `saves\` 아래 월드별 `.dat` 파일로 저장합니다. 해당 위치를 쓸 수 없는 환경에서는 실행 폴더 안의 `.mineworld-game-project\`를 사용합니다. 마우스 감도와 픽셀 배율도 저장 폴더의 `options.properties`에 저장됩니다.
