# Mineworld game project

Java 21과 LWJGL 3로 만든 1인칭 복셀 샌드박스 프로토타입입니다. 지형과 나무가 생성되는 월드에서 블록을 캐고 설치할 수 있으며, 월드는 사용자 홈 폴더에 저장할 수 있습니다.
화면 밖 청크는 시야 절두체로 제외하며, 기본 시야 거리는 64블록입니다.
블록은 위쪽에서 받는 햇빛과 횃불 주변 조도에 따라 밝기가 달라지고, 물은 반투명 표면으로 표시됩니다.
평원·산악·해변·사막 생물군계가 작은 지역 단위로 생성되며, 시작 지점은 평원입니다. 마우스 휠로 핫바를 순환하고 선택한 블록이나 횃불이 화면 오른손에 표시됩니다. 5분 주기의 새벽·낮·노을과 달 위상, 별, 별똥별이 표시되며 완전한 밤 없이 주변 밝기를 유지합니다.

## 실행

Windows에서 Java 21을 설치한 뒤 저장소 루트에서 실행합니다.

```powershell
.\gradlew.bat run
```

## 조작

| 입력 | 동작 |
| --- | --- |
| W/A/S/D 또는 방향키 | 이동 |
| Space 한 번 | 점프 |
| Space 빠르게 두 번 | 비행 켜기/끄기 |
| 비행 중 Space 길게 누르기 | 상승 |
| 비행 중 Left Shift 길게 누르기 | 하강 |
| Left Shift (비행 중이 아닐 때) | 달리기 |
| 마우스 이동 | 시점 회전 |
| 왼쪽 클릭 | 바라보는 블록 캐기 |
| 오른쪽 클릭 | 선택한 블록 설치 |
| 1–9 | 핫바 선택 |
| Esc | 마우스 커서 해제 |
| F3 | 마우스 다시 잠금 |
| F5 | 월드 저장 |
| F9 | 저장된 월드 불러오기 |

월드 저장 파일은 `%USERPROFILE%\.mineworld-game-project\world.dat`에 생성됩니다.
